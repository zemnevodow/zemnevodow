## 🏛️ Agora — my main product

<img align="right" width="300" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" alt="building" />

**Agora** is an **open-source, self-hosted** toolkit for community builders.
The goal: become the *first thought* of every community manager — instead of MEE6.

- 🔓 **100% open source** — no paywalled features, no lock-in
- 🏠 **Self-hosted** — your community, your data, your server
- ⚡ **Fast activation** — from install to a living community in minutes
- 🤖 **AI-native** — built with and for modern AI workflows

> ⭐ Star it, fork it, break it, improve it. Contributors welcome!
