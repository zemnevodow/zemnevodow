## Точка безубыточности

```
Постоянные расходы:  $5,200 /мес
Маржа с ведения:     $2,800 /мес на клиента
Маржа с подготовки:  $5,500 (разово)

С 1 клиентом (подготовка + ведение):
  Месяц 1: $6,000 + $3,500 - $500 - $700 - $5,200 = +$3,100
  Месяц 2+: $3,500 - $700 - $5,200 = -$2,400

→ 1 клиент на ведении не покрывает постоянные расходы
→ Нужно: 2 клиента на ведении = $2,800 × 2 = $5,600 > $5,200 ✓
```

**Минимум для выхода в плюс: 2 клиента на ведении сезона одновременно**
