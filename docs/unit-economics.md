## Ценообразование (от расходов + маржа)

### Рекомендуемые пакеты

| Пакет | Что входит | Цена /мес | COGS /проект | Маржа | Маржинальность |
|-------|-----------|-----------|-------------|-------|---------------|
| **Starter** | SMM + Community + модерация | **$5,000** | ~$2,500 | $2,500 | 50% |
| **Standard** | Starter + Airdrop Campaign + трафик | **$10,000** | ~$4,000 | $6,000 | 60% |
| **Premium** | Standard + KOL + амбассадоры + BD | **$15,000** | ~$5,500 | $9,500 | 63% |

> Starter — для входа, показать результат на малой работе. Standard — основной продукт (как Nomisma). Premium — полный сервис.

### Почему такие цены

**$5K Starter:**
- Порог входа для клиента невысокий
- Покрывает работу 1 основателя part-time
- Можно апсейлить в Standard после первых результатов

**$10K Standard (основной продукт):**
- Полноценный airdrop campaign — как Nomisma Network
- При 1 клиенте: $10K - $5,800 = **$4,200 прибыли** (42%)
- При 2 клиентах: $20K - $6,500 = **$13,500 прибыли** ($6,750 на каждого)

**$15K Premium:**
- Добавляется KOL бюджет менеджмент, BD, амбассадоры
- При 1 клиенте: $15K - $5,800 = **$9,200 прибыли** (61%)

## Точка безубыточности

### Постоянные расходы /мес (без клиентов)

| Статья | Сумма |
|--------|-------|
| Зарплаты основателей (минимум) | $5,000 |
| Общие подписки и инструменты | $100 |
| Маркетинг агентства (контент, домен) | $200 |
| **Итого постоянные** | **$5,300** |

### Расчёт

```
Точка безубыточности = Постоянные расходы / Маржа на проект
= $5,300 / $4,700 (Standard, без доп. расходов на фриланс)
= 1.13 проекта
```

**Для выхода в ноль нужно: 1 клиент Standard ($10K)**

**Для комфорта (>$5K прибыли сверх зарплат): 2 клиента Standard**
