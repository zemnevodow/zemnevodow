## Слайд 2: Проблема

### С чем сталкиваются Web3 проекты

- Запустили продукт, но нет пользователей и комьюнити
- Не знают как правильно провести airdrop кампейн
- Пробовали сами — получили ботов вместо реальных пользователей
- Нанимали фрилансеров — нет синхронности, результат слабый
- Нужен трекшн перед TGE / раундом, а времени мало

**Результат:** проект теряет время, деньги и momentum

---

## Слайд 3: Решение

### Полный запуск airdrop кампейна под ключ

Одна команда закрывает все процессы:

| BD | Партнёрства, интеграции |
| Тех саппорт | Поддержка пользователей, FAQ |

## Слайд 4: Как это работает

```
Discovery Call → Стратегия → Запуск → Масштабирование → Отчёт
   (1 день)     (1 неделя)  (2 нед)    (ongoing)      (еженедельно)
```

1. **Discovery Call** — разбираем проект, цели, аудиторию
2. **Стратегия** — план кампейна, механика квестов, KOL лист, контент план
3. **Запуск** — настройка каналов, старт контента и кампейна
4. **Масштабирование** — оптимизация по данным, новые волны KOL
5. **Отчётность** — еженедельные отчёты с метриками
