# Должностные инструкции основателей

## Зачем это нужно

Чёткое разделение зон ответственности между основателями предотвращает конфликты, дублирование работы и пробелы в управлении. Каждый знает за что отвечает и по каким метрикам оценивается.

---

## Основатель 1: [Имя] — CEO / Head of Growth

### Зона ответственности
- **Стратегия агентства** — видение, направление развития, ценообразование
- **Продажи и BD** — привлечение новых клиентов, переговоры, закрытие сделок
- **Управление клиентами** — ключевой контакт для топовых клиентов
- **Продукт** — развитие квест-платформы и услуг агентства
- **Финансы** — P&L, бюджетирование, cash flow

### Процессы
| Процесс | Частота | Описание |
|---------|---------|----------|
| Sales pipeline review | Еженедельно | Обзор воронки продаж, статус лидов |
| Client check-in | Еженедельно | Звонок с ключевыми клиентами |
| Стратегическое планирование | Ежемесячно | Обзор метрик, планы на месяц |
| Финансовый обзор | Ежемесячно | P&L, cash flow, прогнозы |

|---------|------|
| Новых клиентов /мес | [X] |
| Retention rate | [XX]%+ |
| Выручка /мес | $[XX,XXX]+ |
| NPS клиентов | [X]+ |

### Принятие решений
- **Самостоятельно:** найм до $[X,XXX]/мес, маркетинговый бюджет до $[X,XXX], оперативные решения по клиентам
- **Совместно с партнёром:** найм ключевых позиций, пакеты/цены, крупные партнёрства, стратегические изменения

## Основатель 2: [Имя] — COO / Head of Operations

### Зона ответственности
- **Операционка** — управление командой, процессы, качество
- **Delivery** — контроль выполнения проектов в срок и с результатом
- **Команда** — найм, онбординг, обучение, мотивация
- **Маркетинг агентства** — контент, соц сети, YouTube, бренд
- **Процессы** — документация, шаблоны, автоматизация

### Процессы
| Процесс | Частота | Описание |
|---------|---------|----------|
| Team standup | Ежедневно | Синхронизация с командой, блокеры |
| Project review | Еженедельно | Статус каждого проекта, метрики |
| Team 1-on-1 | Еженедельно | Индивидуальные встречи с ключевыми сотрудниками |
| Процесс-ревью | Ежемесячно | Оптимизация процессов, автоматизация |

### KPI
| Метрика | Цель |
|---------|------|
| Проекты в срок | [XX]%+ |
| Удовлетворённость клиентов | [X]/10+ |
| Текучка команды | <[XX]% /год |
| Контент (посты /нед) | [X]+ |

### Принятие решений
- **Самостоятельно:** распределение команды по проектам, операционные бюджеты до $[X,XXX], контент стратегия
- **Совместно с партнёром:** найм ключевых позиций, изменение процессов delivery, стратегические изменения

## Процесс принятия решений

### Оперативные решения (< $[X,XXX])
- Каждый принимает в своей зоне самостоятельно
- Информирует партнёра в общем чате

### Тактические решения ($[X,XXX] — $[XX,XXX])
- Обсуждение на еженедельном sync
- Решение принимает тот, в чью зону входит, с учётом мнения партнёра

### Стратегические решения (> $[XX,XXX] или влияние на бизнес)
- Обязательное согласие обоих основателей
- Если нет согласия — берём паузу на 48 часов, потом обсуждаем снова
- Если и после — привлекаем внешнего ментора/советника
